# เปิดแจ้งเตือน LINE

ระบบส่ง "การ์ดสถานะ" เข้ากลุ่ม LINE ของงานพัสดุโดยอัตโนมัติเมื่อมีการ **ส่งพิจารณา / อนุมัติ / ส่งกลับแก้ไข**
และมีปุ่ม **ส่งสถานะเข้า LINE** ในหน้าโครงการสำหรับส่งซ้ำหรือแนบลิงก์เอกสาร

ใช้ **LINE Messaging API** (LINE Notify ยุติบริการแล้วเมื่อ 31 มี.ค. 2568) ตั้งค่าครั้งเดียว ประมาณ 10 นาที ไม่มีค่าใช้จ่าย
สำหรับปริมาณข้อความของหน่วยงานทั่วไป (แผนฟรีของ LINE OA ส่งได้หลายร้อยข้อความต่อเดือน — ตรวจโควตาปัจจุบันที่ lineforbusiness.com)

## 1. สร้างบัญชี LINE Official Account และเปิด Messaging API

1. เข้า https://developers.line.biz/console/ ด้วยบัญชี LINE ของหน่วยงาน → **Create a new provider** (ชื่อหน่วยงาน)
2. **Create a Messaging API channel** → กรอกชื่อ (เช่น "แจ้งเตือนจัดซื้อจัดจ้าง") หมวดหมู่ และรูปโปรไฟล์ → สร้าง
3. แท็บ **Basic settings** → คัดลอก **Channel secret**
4. แท็บ **Messaging API** → **Issue** Channel access token (long-lived) → คัดลอก
5. ในแท็บเดียวกัน:
   - **Allow bot to join group chats** → เปิด
   - **Auto-reply messages** → ปิด (ไม่อย่างนั้นบอทจะตอบข้อความในกลุ่ม)

## 2. ใส่ค่าในเซิร์ฟเวอร์

| ค่า | ที่มา |
|---|---|
| `PROC_LINE_CHANNEL_ACCESS_TOKEN` | Channel access token จากข้อ 1.4 |
| `PROC_LINE_CHANNEL_SECRET` | Channel secret จากข้อ 1.3 |

- **Render:** service `procurement` → **Environment** → Add → ใส่ทั้งสองค่า → **Save Changes** (Render จะ deploy ใหม่เองประมาณ 1–2 นาที)
- **Docker Compose:** ใส่ใน `deploy/.env` แล้ว `./install.sh --no-build`

ตรวจที่หน้าเว็บ: **ผู้ดูแลระบบ → กลุ่ม LINE** ช่อง "การตั้งค่า LINE" ต้องขึ้น ✓ ทั้ง Channel access token และ Channel secret

## 3. ตั้ง Webhook (ให้ระบบรู้จักกลุ่มเอง)

1. ที่หน้า **ผู้ดูแลระบบ → กลุ่ม LINE** กด **คัดลอก** Webhook URL (รูปแบบ `https://<โดเมน>/api/line/webhook`)
2. LINE Developers Console → แท็บ **Messaging API** → **Webhook URL** → วาง → **Update** → **Verify** (ต้องขึ้น Success)
3. เปิด **Use webhook**

ระบบตรวจลายเซ็น `X-Line-Signature` ด้วย Channel secret ทุกครั้ง คำขอที่ไม่ได้มาจาก LINE จะถูกปฏิเสธ (403)
และ webhook ทำแค่ "จดจำกลุ่ม" เท่านั้น ไม่ตอบข้อความและไม่ส่งข้อมูลระบบออกไป

## 4. เชิญบอทเข้ากลุ่ม

1. ในแอป LINE เพิ่มบัญชี OA เป็นเพื่อน (QR อยู่ที่แท็บ Messaging API) แล้ว **เชิญเข้ากลุ่ม** งานพัสดุ
2. กลุ่มจะปรากฏที่ **ผู้ดูแลระบบ → กลุ่ม LINE** ทันที พร้อมชื่อกลุ่มจาก LINE และป้าย "พบจากการเชิญบอท"
   (ถ้าไม่ปรากฏ ให้ใครก็ได้พิมพ์ `ลงทะเบียน` ในกลุ่ม หรือตรวจข้อ 3 อีกครั้ง)
3. กด **ทดสอบ** → ต้องได้รับข้อความ "✅ ทดสอบการแจ้งเตือน…" ในกลุ่ม
4. กด **เปิดใช้** — จากนี้ทุกการส่งพิจารณา/อนุมัติ/ส่งกลับจะแจ้งเข้ากลุ่มนี้

เอาบอทออกจากกลุ่ม → ระบบปิดกลุ่มนั้นให้เองและบันทึกใน audit log

## สิ่งที่ส่งเข้า LINE และสิ่งที่ไม่ส่ง

| ส่ง | ไม่ส่ง |
|---|---|
| เลขที่/ชื่อโครงการ วิธีจัดหา ขั้นตอน สถานะ วงเงิน และชื่อผู้ดำเนินการ | ไฟล์เอกสาร ข้อมูลผู้ประกอบการ เลขประจำตัวประชาชน บัญชีธนาคาร |
| ปุ่ม "เปิดเอกสาร" เป็น**ลิงก์อายุ 60 นาที** และผู้กดต้อง**เข้าสู่ระบบ**ก่อนจึงดาวน์โหลดได้ | ลิงก์ที่เปิดได้โดยไม่ต้องเข้าสู่ระบบ |

ทุกการส่งบันทึกใน `notification_logs` (สำเร็จ/ล้มเหลว) และ audit log · LINE ล่มไม่ทำให้การบันทึกงานล้มเหลว (ส่งใน background)

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| Verify webhook ขึ้น error | URL ผิด หรือ Channel secret ในเซิร์ฟเวอร์ไม่ตรงกับ Console → ตรวจค่า `PROC_LINE_CHANNEL_SECRET` แล้ว deploy ใหม่ |
| เชิญบอทแล้วกลุ่มไม่ปรากฏ | ยังไม่เปิด **Use webhook** หรือ Verify ไม่ผ่าน · ลองพิมพ์ `ลงทะเบียน` ในกลุ่ม |
| ทดสอบแล้ว "LINE ตอบกลับ HTTP 401" | Channel access token ผิดหรือหมดอายุ → Issue ใหม่แล้วอัปเดตค่า |
| ทดสอบแล้ว "LINE ตอบกลับ HTTP 403/404" | บอทไม่ได้อยู่ในกลุ่มแล้ว หรือ groupId ที่กรอกเองผิด |
| ส่งอัตโนมัติไม่มา แต่ทดสอบได้ | กลุ่มยังไม่ **เปิดใช้** หรือ `PROC_LINE_AUTO_NOTIFY=0` |
| ชื่อกลุ่มขึ้น "กลุ่มใหม่ (รอตั้งชื่อ)" | LINE ไม่ให้สิทธิ์อ่านชื่อกลุ่ม (ปกติสำหรับ OA บางประเภท) → กด "แก้ชื่อ" ตั้งเอง |
